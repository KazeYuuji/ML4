Model Overview

The Camera Price Predictor uses a Random Forest Regressor model trained on a dataset of camera specifications and prices. The model analyzes various technical features to predict the market price of a camera.

Model Performance

  • Model Type: Random Forest Regressor
  • Test R² Score: > 0.8
  • Cross-Validation R² Score: > 0.8
  • Mean Absolute Percentage Error (MAPE): < 20%

Feature Engineering

The model uses both original features and engineered features to improve prediction accuracy:

  • Original features: Resolution, zoom capabilities, weight, dimensions, etc.
  • Engineered features: Zoom ratio, resolution ratio, megapixels, weight per megapixel, size efficiency, camera age
  • Categorical encoding: Brand information is encoded and included as features

Model Limitations

  • Predictions are based on historical data and may not account for market trends
  • Accuracy varies by price range (better for mid-range cameras)
  • Unknown brands are handled with default encoding
  • The model assumes standard market conditions

Future Improvements

  • Collect more data for premium cameras to improve accuracy
  • Consider additional features like sensor size, ISO range
  • Try ensemble methods combining multiple models
  • Implement time-series analysis to account for price depreciation
